**What must be true.** A refusal the Git store hands the window names no local path on any system the planner runs
on, and still names the field a fault concerns.

## Plan

- Today a local path is scrubbed from a refusal by a pattern of Unix paths: a Windows drive path, such as one of
  the planner's scratch directory, passes it; and a fault naming a field by its JSON pointer, as `/size: a dash`,
  has the pointer taken for a path and replaced.
- Red first: a refusal over a scratch path `C:\Users\...` names no drive path, and one over `/size:` keeps it.
